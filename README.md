# The Shattered Crown

This repo contains _The Shattered Crown_, a RimWorld mod.

This mod adds a new scenario, "The Shattered Crown", which includes:
* Bespoke NPC characters, including some recruitable ones
* Dialogue trees
* A class system
* Proficiencies + die rolls
* Magic spells, and a new resource (Energy)

There are some AI-built tools that make this feasible:

* A dialogue DSL + compiler that makes it easier to write NPC/companion dialogue
* A dialogue tester application (Windows/WPF)
